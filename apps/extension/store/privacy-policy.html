SnapURL Browser Extension — Privacy Policy

Last updated: 2026-09-14

SnapURL is a browser extension that shortens the current tab against your own SnapURL API. You point it at an API base URL you control and authenticate with a key you issue. This policy describes exactly what data the extension handles, where it goes, and what it never does.

Summary

  • The extension talks only to the SnapURL API URL you configure — not to the extension authors, Mozilla, Google, or any third party.
  • It stores your API base URL, API key, and an optional default domain in your browser's local extension storage. Nothing is uploaded to us.
  • No analytics, no tracking, no telemetry, no advertising.
  • It requests no access to your browsing. It reads a page's URL and title only when you explicitly ask it to shorten that page.
  • Nothing is ever sold or shared.

What data the extension handles

Settings you enter (stored locally):

  • API base URL — the address of your SnapURL instance.
  • API key — a scoped SnapURL key (snap_live_…) you generate. A secret; stored and never logged.
  • Default domain (optional) — a short domain to use by default.

Stored via chrome.storage.local on your device. Never transmitted anywhere except as the Authorization header on requests to the API base URL you configured.

Data you choose to act on (sent to your API only):

  • Shortening a page sends its URL (plus any custom alias / UTM parameters you add) to POST <your-api-base>/api/v1/links.
  • Searching / viewing recent links sends a search query to GET <your-api-base>/api/v1/links.
  • Picking a domain reads your configured domains from GET <your-api-base>/api/v1/domains.

Every request goes only to the API base URL you set, carrying your API key as a Bearer token. The extension makes no other network requests.

What the extension does NOT do

  • Does not read, monitor, or collect your browsing history or page content. No host permissions (host_permissions: []), no <all_urls>. It reads only the tab you explicitly shorten, via activeTab.
  • Does not send data to the developers or to any analytics/ad/tracking service.
  • Contains no remote code. All logic ships in the extension (MV3, strict CSP, no eval).

Permissions and why

  • activeTab — read the current tab's URL/title only when you invoke "Shorten".
  • storage — save your API URL, key, and default domain locally.
  • contextMenus — the "Shorten with SnapURL" right-click item.
  • commands (top-level key) — the keyboard shortcut.
  • No host permissions.

Data retention and deletion

Your settings live in your browser's extension storage until you clear them (options page, removing the extension, or clearing browser data). The extension keeps no server-side copy — it has no server of its own. Links you create live in your SnapURL instance under its own retention.

Data sharing and sale

None. The only network destination is the SnapURL API you configure and control.

Children

A developer/productivity tool, not directed at children.
